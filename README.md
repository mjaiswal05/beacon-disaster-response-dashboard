# Beacon – Disaster Response Dashboard

## Overview
Beacon is a city-level disaster response dashboard designed to help emergency teams monitor, manage, and respond to incidents in real time. It provides a centralized platform for tracking emergencies, coordinating resources, and enabling data-driven decision-making.

## Features
- Real-time incident tracking and monitoring  
- Emergency alerts and notification system  
- Resource allocation and coordination  
- Data visualization and analytics dashboard  
- Interactive mapping for incident locations
